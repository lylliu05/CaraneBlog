# CaraneBall · 引力球关系图（Android）

用「引力球」模拟人际关系的安卓应用：每个人是一个球，关系越深互相吸引越强；**你**固定在底部中心，其余球自由运动。

## 核心玩法

- **你 = 金色球**：固定在底部中心，是整张图的引力中心。
- **新建球**：右下角 ＋ → 新建人物。
- **新建事件**：右下角 ＋ → 新建事件，勾选参与的人，事件让参与者**两两关系加深**（+N）。
- **关系加深 → 互相吸引**：两个人关系越深，连线越亮越粗、球靠得越近。
- **体积 = 人缘**：与越多的人关系越深，球越大（按加权关系度计算）。
- **点击球**：查看详情 —— 加深关系（+10）、添加关系（初始 30）、删除关系、删除人物、改名字。
- **拖动球**：手动调整任意球位置（“我”固定不可拖）。

## 操作入口

| 操作 | 方式 |
| --- | --- |
| 新建人物 / 新建事件 / 事件记录 | 右下角金色 ＋ 按钮 |
| AI 接入设置（可选） | ＋ 菜单 → AI 接入设置 |
| 查看 / 编辑某个人 | 点击对应球 |
| 移动球 | 按下拖动（“我”固定） |
| 数据保存 | 自动存入本地（SharedPreferences / JSON），重启不丢 |

## AI 判定变化度（可选，需自备大模型 API）

在 ＋ 菜单「AI 接入设置」中填写 OpenAI 兼容 API（地址 / Key / 模型，支持豆包火山方舟、DeepSeek、OpenAI、智谱等）并保存，可先点「测试连接」验证。

- 新建事件时点击「AI 判定变化度」：App 会把事件名称、参与者名单及当前关系强度发给大模型，AI 返回关系变化量（-50 ~ +50）并自动填入滑块；
- 填入后仍可手动拖动滑块微调；
- **未接入大模型时**：AI 按钮会提示先配置，滑块手动使用，功能不受影响。

> 配置说明：endpoint 填基础地址（如 `https://ark.cn-beijing.volces.com/api/v3`），App 自动拼接 `/chat/completions`。API Key 明文保存在本地（个人使用）；正式发布建议改为加密存储。

```

├── MainActivity.kt        # 主界面：对话框、详情面板、事件流程
├── model/Universe.kt      # 数据模型：人物 / 关系 / 事件 + JSON 序列化
├── data/Store.kt          # 本地持久化（SharedPreferences）
└── view/GravityView.kt    # 引力球画布：物理模拟 + 绘制 + 手势
preview/引力球演示.html      # 浏览器概念演示（同一套物理，可先体验交互）
```

## 物理模型（GravityView）

- 两两**排斥力** `F = k / (d + s)²`：防止球体重叠；
- 有关系的人之间有**弹簧引力**，静息距离随关系强度减小 → 关系越深越靠近；
- 所有球对“我”有**弱引力**：整张图始终以你为中心；
- 速度阻尼 + 边界反弹：自动稳定成图，无需手动布局。

## 构建运行

1. 环境要求：JDK 17+（Android Studio 自带）、Android SDK（compileSdk 34）。
2. 用 Android Studio 打开项目根目录，等待 Gradle 同步（wrapper 使用 Gradle 8.14.5）。
3. 运行到模拟器 / 真机（minSdk 26，Android 8.0+）。

> 命令行构建：`gradlew assembleDebug`（首次会下载依赖，需要网络）。
