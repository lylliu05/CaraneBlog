# 爱日常 CaraneLoveLife

一款**日常记录类** Android 应用，把生活的琐碎与心动都收进一个 App：**日记记录、账单汇总**是核心双引擎，同时贴心内置**经期**记录与**恋爱/暗恋**专属空间。纯本地存储，数据不上云，安心记录每一天。

> 定位：日常类应用。主推**日记记录**（写心情、配图、选天气、记类型）与**账单汇总**（导入/录入、分类、月度报告），恋爱与经期作为温暖的情感陪伴模块。

---

## ✨ 核心功能

### 📝 日记记录（核心）
- **两类日记**：日常日记（"一刻"页签）与 情侣日记（从恋爱页进入，自动归类，列表带 ❤ 标志）
- **心情 + 天气**：8 种心情 emoji、12 种天气（含"晴转多云""晴转雷阵雨"等组合）
- **图片配图**：每条日记可添加多张图片，列表缩略图预览，点击可移除
- **时间轴视图**：按日期倒序，同一天自动合并，友好展示"今天/昨天/M月d日"
- 底部导航"一刻"页签，快速记录当下的每一刻

### 💰 账单汇总（核心）
- **多来源导入**：支付宝/微信 CSV 账单、银行流水、手动录入
- **智能解析**：预览确认后导入，自动去重（重复记录自动跳过）
- **账单明细**：搜索、按类型/分类/支付方式/来源多维筛选
- **数据报告**：月度收支热力图、分类占比、趋势对比、消费 Top 明细
- 完整记录每笔支出/收入，随时掌握收支状况

### 💘 恋爱 / 暗恋空间
- **阶段时间线**：相识 → 暗恋 → 恋爱 → 结婚，点击切换查看，点击天数修改日期
- **恋爱天数**：按当前阶段展示"在一起/相识/暗恋/结婚"的天数
- **阶段纪念日**：相识/暗恋/恋爱/结婚纪念日自动生成，每年重复、倒计时提醒
- **自定义头像**：默认按阶段与性别分配（女生镜像翻转），可更换自己的图片
- **单头像模式**：暗恋只显示暗恋对象，恋爱/结婚居中显示代表头像

### 🌸 经期管理
- 经期记录与**预测**（日历标注经期/预测经期/排卵期/排卵日）
- 每日详细记录：流量、颜色、痛经、症状、心情、体重、体温、小记
- 自动计算周期长度与经期天数，也可手动设置

### 其他
- 共同**愿望清单**：卡片打卡，可多次完成，时间线记录每次完成日期
- **纪念日**：自定义纪念日，每年重复，倒计时/已过天数
- **开屏壁纸**：可自定义情侣合照
- **主题**：跟随系统 / 浅色 / 深色（克莱因蓝配色）
- **数据备份**：JSON 导入导出，随时迁移

## 技术栈

- Kotlin 1.9.22 / AGP 8.2.2 / Gradle 8.5 / JDK 21(AS 内置 JBR)
- compileSdk 34 / minSdk 26 / targetSdk 34
- Material 3(Theme.Material3.DayNight)+ ViewBinding + 协程
- Room 2.6.1(KSP)+ SharedPreferences 封装(PrefsManager)
- 账单模块基于 Jetpack Compose + Material3 + Navigation
- 配色:克莱因蓝 v2.0 规范(明:蓝调灰 #F2F5FA;暗:深蓝黑 #0D1117;强调色:暖铜)

## 页面结构

| 模块 | 说明 |
|---|---|
| 一刻（日记） | 日常日记记录，心情/天气/配图，底部导航最左侧，不可隐藏 |
| 恋爱 | 阶段时间线、恋爱天数、纪念日、愿望清单、情侣日记入口 |
| 经期 | 经期记录与预测、每日健康日志 |
| 账单 | 数据导入/录入、明细筛选、月度报告 |
| 设置（侧边栏） | 主题、页面显示开关、开屏壁纸、数据导入导出、检查更新 |

## 编译

### 依赖源(强制镜像)

`settings.gradle.kts` 已强制阿里云镜像优先(google/public/central/gradle-plugin),官方源仅兜底;
Gradle wrapper 发行版同样走阿里云镜像(`gradle/wrapper/gradle-wrapper.properties`)。

### 本机环境说明(重要)

本机 AS 内置 jbr 已升级为 **JDK 25**、系统 JDK 为 23,均超出 AGP 8.2.2 支持范围(17~21)。
构建必须使用本机现存的 **JDK 21**:`C:\Users\l\.jdks\jbr-21.0.11`。

### 命令行构建(全局 Gradle 8.5 + JDK 21)

```powershell
$env:JAVA_HOME='C:\Users\l\.jdks\jbr-21.0.11'
& 'D:\Androidstudio\gradle\gradle-8.5\bin\gradle.bat' assembleDebug --console=plain
```

备选:全局 8.14.5 实测可用(`D:\Androidstudio\gradle\gradle-8.14.5`);wrapper 兜底(发行版走阿里云镜像,已缓存)

APK 输出:`app/build/outputs/apk/debug/app-debug.apk`(已验证可构建)

或直接用 Android Studio 打开工程构建(请在 AS 中将 Gradle JDK 指向上述 JDK 21)。

## 工程结构

```
app/src/main/java/com/caranelovelife/
├── App.kt                  # 全局单例(数据库/仓库/偏好)
├── core/
│   ├── data/               # PrefsManager + 仓库 + 备份 + 默认愿望
│   └── db/                 # Room 实体/DAO/数据库(迁移)
├── ui/
│   ├── main/               # 底部导航 + 侧边栏(DrawerLayout)
│   ├── home/               # 恋爱首页(阶段/天数/头像/纪念日)
│   ├── diary/              # 一刻日记(日常/情侣,心情天气配图)
│   ├── period/             # 经期记录与预测
│   ├── wish/               # 愿望清单(多次完成时间线)
│   ├── anniversary/        # 纪念日(含阶段纪念日)
│   ├── onboarding/         # 开局引导
│   └── us/                 # 设置侧边栏
├── biller/                 # 账单模块(Compose:导入/明细/报告)
└── util/                   # DateUtils / ImageStore / 完成日期工具
```
