# 爱生命 CaraneLoveLife

一款**生活经营类** Android 应用，以"爱生命"为核心理念——**记录每一天、守护健康、经营关系**。日记与账单承载生活记录，经期/运动/睡眠守护健康，恋爱空间与关系图经营人与人之间的联结。纯本地存储，可选云端情侣绑定同步，安心记录每一天。

> 定位：生活经营类应用。三大方向——**生活记录**（日记、账单、数据卡片）、**健康守护**（经期、运动、睡眠、生活状态评分）、**关系经营**（恋爱空间、关系图、云端绑定、人格测试）。不再以恋爱为唯一核心，而是珍视生命的每一面。

---

## ✨ 核心功能

### 📝 生活记录
- **日记（一刻）**：日常日记 + 情侣日记双类型，心情/天气标签，多图配图，按日合并的时间轴
- **账单**：支付宝/微信 CSV 导入、银行流水、手动录入，自动去重；明细多维筛选；月度热力图、分类占比、趋势对比、消费 Top 报告
- **数据记录卡片**：自定义卡片（如体重、血压），多字段表单，历史记录与趋势

### ❤️ 健康守护
- **经期管理**：记录与预测（经期/预测经期/排卵期/排卵日），每日健康日志（流量、颜色、痛经、症状、心情、体重、体温、小记）
- **运动**：今日步数（系统计步）、跑步/步行/骑行/自由训练、运动中实时数据（时长/距离/配速/消耗）、历史记录与成就
- **睡眠监测**：睡前一键开始，噪音分贝采样与睡眠阶段记录、助眠白噪音、入睡/醒来时间
- **生活状态评分**：综合近 7 天睡眠/运动/日记/生活/工作数据，生成今日状态评价与改善建议

### 💘 关系经营
- **恋爱空间**：阶段时间线（相识→暗恋→恋爱→结婚）、恋爱天数、自动纪念日、自定义头像、好感度互动、共同愿望清单（多次完成时间线）
- **恋爱模式**：异地恋（天数计时）、备孕（排卵日提醒）、冷战记录（和好自动结束）
- **关系图**：以物理引力模拟人际关系的远近，人物/事件节点可视化，GPS 修正关系强度、AI 事件分析接入
- **恋爱绑定（云端）**：Supabase 注册身份 → 6 位邀请码绑定，情侣日记/愿望/纪念日自动同步；可选共享位置（每分钟上报）与正在使用的应用
- **人格测试**：MBTI 16 题测试与情侣配对、大五人格测试，结合近期数据验证与成长建议

### 🌦️ 更多
- **城市天气**：我的城市/对方城市双天气、未来 24 小时、降水雷达地图
- **首页今日概览**：天气、农历、时间、昨夜睡眠、步数、生活状态一站式查看
- **翻页时钟**：横屏全黑、防烧屏（像素漂移+亮度呼吸）、自动息屏
- **开屏壁纸**：默认克莱因蓝 + 生命嫩芽开屏，可自定义情侣合照
- **主题**：跟随系统 / 浅色 / 深色（克莱因蓝 v2.0 配色）
- **数据备份**：ZIP 打包（含日记配图、头像、壁纸），可选密码加密，导入覆盖
- **应用内更新**：检查更新、下载、自动安装

## 技术栈

- Kotlin 1.9.22 / AGP 8.2.2 / Gradle 8.5 / JDK 21(AS 内置 JBR)
- compileSdk 34 / minSdk 26 / targetSdk 34
- Material 3(Theme.Material3.DayNight)+ ViewBinding + 协程
- Room 2.6.1(KSP)+ SharedPreferences 封装(PrefsManager)+ security-crypto 加密存储
- 账单模块基于 Jetpack Compose + Material3 + Navigation
- osmdroid 降水雷达地图；Supabase 云端绑定与同步（Retrofit 风格自研 Client）
- 配色:克莱因蓝 v2.0 规范(明:蓝调灰 #F2F5FA;暗:深蓝黑 #0D1117;强调色:暖铜)

## 编译

### 依赖源(强制镜像)

`settings.gradle.kts` 已强制阿里云镜像优先(google/public/central/gradle-plugin),官方源仅兜底;
Gradle wrapper 发行版同样走阿里云镜像(`gradle/wrapper/gradle-wrapper.properties`)。

### 本机环境说明(重要)

本机 AS 内置 jbr 已升级为 **JDK 25**、系统 JDK 为 23,均超出 AGP 8.2.2 支持范围(17~21)。
构建必须使用本机现存的 **JDK 21**:`C:\Users\l\.jdks\jbr-21.0.11`。

### 命令行构建(全局 Gradle 8.5 + JDK 21)

```powershell
$env:JAVA_HOME='C:\Users\l\.jdks\jbr-21.0.11'
& 'D:\Androidstudio\gradle\gradle-8.5\bin\gradle.bat' assembleDebug --console=plain
```

备选:全局 8.14.5 实测可用(`D:\Androidstudio\gradle\gradle-8.14.5`);wrapper 兜底(发行版走阿里云镜像,已缓存)

APK 输出:`app/build/outputs/apk/debug/app-debug.apk`(已验证可构建)

或直接用 Android Studio 打开工程构建(请在 AS 中将 Gradle JDK 指向上述 JDK 21)。
